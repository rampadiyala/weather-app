# Weather App

Search a city to see its current temperature and daily forecast.

## Features

- City search
- Current temperature and daily minimum and maximum
- Loading and error messages

## Tech stack

HTML, CSS, JavaScript, Open-Meteo API

## How to run

`npm start` (needs Python 3), then open http://localhost:8000. Internet access is required. No packages to install.

## Project files

- `index.html` - page and styles
- `app.js` - API requests and display

## Notes

Weather data comes from Open-Meteo.com. Check its terms of use. The search uses the first matching city.
